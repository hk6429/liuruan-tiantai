# 字詞注釋（國中程度）

G＝[《太平廣記》卷六十一〈天台二女〉](https://zh.wikisource.org/zh-hant/太平廣記/卷第061#天台二女)；Y＝[《太平御覽》卷四十一引《幽明錄》](https://zh.wikisource.org/wiki/太平御覽/0041#天台山)；E＝[《藝文類聚》卷七引《幽明錄》](https://zh.wikisource.org/zh-hant/藝文類聚/卷007#天台山)；L＝[ctext《古小說鉤沉》第 182 段](https://ctext.org/wiki.pl?chapter=798132&if=en)。代號超連結即每條例句出處；L 尚未影像核字。

先列 G 用語；第二表為任務指定的他本詞彙，不能因此加入 G 的台詞。引文保留見證字形，注釋使用台灣繁體中文。不取留宿段作例句。

## 他本補充詞彙

| 字詞 | 注釋與版本界線 | 例句與出處 |
|---|---|---|
| 穀皮 | 穀樹的樹皮，通常解作構樹（楮樹）的樹皮；不是稻穀的殼。此為他本採集物，G 只稱採藥。 | 「共入天台取穀皮」〔Y〕；植物名稱參[農業部資料，構樹條](https://kmweb.moa.gov.tw/redirect_files.php?id=9419)。 |
| 餒 | ㄋㄟˇ，飢餓。「殆死」指幾乎死去。 | 「饑餒殆死」〔Y〕 |
| 邃澗 | 邃，ㄙㄨㄟˋ，深遠；澗，ㄐㄧㄢˋ，山間水道。幽深的山澗。 | 「而絕岩邃澗，了無登路」〔Y〕；巖／岩依見證字形記錄。 |
| 噉 | ㄉㄢˋ，吃。任務列此字，**本輪讀到 G 作啗、Y 作啖、L 該處缺字**；不假造含「噉」的本文例句。 | 對照例句「啗數枚」〔G，P02〕、「啖數枚」〔Y〕。噉在本文何本用字待人工判斷。 |
| 盥漱 | ㄍㄨㄢˋ ㄕㄨˋ，洗手、漱口。G 沒有此詞。 | 「持杯取水，欲盥漱」〔Y〕 |
| 胡麻飯糝 | 加芝麻的飯粒。糝，ㄙㄢˇ，此處解飯粒，不能譯成稀飯。Y 簡作「胡麻糝」，G 只寫胡麻飯。 | 「有胡麻飯糝」〔L〕；「有胡麻糝」〔Y〕；糝之義參[教育部異體字字典](https://dict.variants.moe.edu.tw/dictView.jsp?ID=66282&la=0)。 |
| 去人徑不遠 | 距離人行的路不遠。去，距離；徑，小路。 | 「此處去人徑不遠」〔Y〕；G 推論作「此近人矣」。 |

| 懷土 | 思念故鄉。土指鄉土。 | 「更懷土，求歸甚苦」〔Y〕；「懷土思求歸」〔E〕 |
| 親舊 | 親人與老朋友。 | 「親舊零落」〔Y／E／L〕 |
