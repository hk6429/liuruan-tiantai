# 字詞注釋（C-R1）

唯一例句來源：[《太平御覽》卷四十一引《幽明錄》](https://zh.wikisource.org/wiki/太平御覽/0041#天台山)，依 `sources/liuruan_tw.txt` 校改刪節整理本。例句全部可在現行正文逐字找到；不是從他本補入的遊戲台詞。解釋供國中閱讀，完整改字理由見 `sources/variants.md`。

| 字詞 | 注釋 | 正文例句 |
|---|---|---|
| 剡縣 | 古地名，在今浙江一帶；剡讀ㄕㄢˋ。 | 「剡縣劉晨、阮肇」 |
| 穀皮 | 穀樹的樹皮，通常解作構樹（楮樹）皮；不是稻穀外殼。 | 「共入天台取穀皮」 |
| 迷不得返 | 迷路，無法回去；不得是不能，不是不肯。 | 「迷不得返」 |
| 十餘日 | 十多天；不能改說恰好十三天。 | 「經十餘日」 |
| 乏盡 | 缺乏而用盡。 | 「糧食乏盡」 |
| 饑餒殆死 | 餓得幾乎死去；殆，幾乎。保留底本饑字。 | 「饑餒殆死」 |
| 子實 | 果實，此處指桃子。 | 「大有子實」 |
| 絕岩邃澗 | 陡峭的岩壁與幽深的山澗。 | 「而絕岩邃澗」 |
| 了無 | 完全沒有。 | 「了無登路」 |
| 攀葛 | 攀著葛藤。 | 「攀葛乃得至」 |
| 啖 | 吃，讀ㄉㄢˋ；不換作他本的啗或未經核證的噉。 | 「啖數枚」 |
| 饑止體充 | 飢餓消除，身體恢復充實有力。 | 「而饑止體充」 |
| 盥漱 | 洗手、漱口；盥讀ㄍㄨㄢˋ，漱讀ㄕㄨˋ。 | 「欲盥漱」 |
| 蕪菁 | 一種可食根、葉的蔬菜；本文出現的是葉子。 | 「見蕪菁葉從山腹流出」 |
| 復 | 又、再。 | 「復一杯流出」 |
| 胡麻糝 | 芝麻飯粒；胡麻為芝麻，糝此處指飯粒。Y 沒有飯字，白話可說飯粒。 | 「有胡麻糝」 |
| 去人徑不遠 | 距離人行的小路不遠；去是距離，不是離去。 | 「此處去人徑不遠」 |
| 度山 | 越過山。 | 「度山出一大溪」 |
| 姿質妙絕 | 容貌、姿態十分美好。 | 「姿質妙絕」 |
| 捉向所失流杯來 | 拿著剛才失落而漂走的杯子來；捉是拿，向是剛才。 | 「捉向所失流杯來」 |
| 二郎 | 稱呼劉、阮兩位男子，不指各排行第二。 | 「劉、阮二郎」 |
| 忻喜 | 高興、喜悅；忻通欣，正文保留忻。 | 「相見忻喜」 |
| 要 | 邀請；此義讀ㄧㄠ。 | 「因要還家」 |
| 筒瓦屋 | 覆有筒形屋瓦的房屋；筒說形狀，不能解作銅製屋頂。 | 「家筒瓦屋」 |
| 絳羅帳 | 深紅色薄絲織品做的帷帳；絳讀ㄐㄧㄤˋ。 | 「皆施絳羅帳」 |
| 侍婢 | 服侍人的女子，反映古代身分制度。 | 「床頭各十侍婢」 |
| 敕云 | 吩咐說；此處敕不是指皇帝詔書，云是說。 | 「便敕云」 |
| 瓊實 | 像美玉般珍貴的果實，指先前吃的桃子。 | 「向雖得瓊實」 |
| 虛弊 | 虛弱、疲憊。 | 「猶尚虛弊」 |
| 山羊脯 | 山羊肉乾；脯讀ㄈㄨˇ。 | 「山羊脯」 |
| 行酒 | 斟酒勸飲。 | 「食畢行酒」 |
| 三五 | 三個、五個，泛指幾個，不是十五個。 | 「各持三五桃子」 |
| 忻怖交並 | 高興與害怕兩種情緒交織。 | 「劉、阮忻怖交並」 |
| 遂 | 於是、就；停指停留，該句依主線例外據W改字。 | 「遂停半年」 |
| 懷土 | 思念家鄉；土指鄉土。 | 「更懷土」 |
| 親舊零落 | 親人與老朋友已凋零、離散。 | 「親舊零落」 |
| 邑屋全異 | 村落與房屋完全變了樣；邑是聚落。 | 「邑屋全異」 |
| 無復相識 | 再也沒有認識的人；復是再。 | 「無復相識」 |
| 七世孫 | 傳了七代的後裔；世指世代，不是七歲或固定七百年。 | 「問得七世孫」 |
| 上世 | 前代、祖先所處的年代。 | 「傳聞上世入山」 |

「胡麻飯糝」「此知去人徑不遠」「各噉數枚」「邑屋改異」不是這份正文逐字用語；閱讀提問可談相同意思，但原文欄不得替換。「百鳥鳴呼」保留底本，譯作鳥兒鳴叫。留宿段整段〔略〕，不取其中字詞作例句。
