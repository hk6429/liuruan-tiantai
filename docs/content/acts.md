# 五幕內容契約（C-R1）

底本：[《太平御覽》卷四十一引《幽明錄》](https://zh.wikisource.org/wiki/太平御覽/0041#天台山)。逐字正文見 `sources/liuruan_tw.txt`，校改與刪節見 `sources/variants.md`。白話僅供閱讀輔助，不是新增人物台詞。

依 plan 第一節教學目標與第三節流程編排；主線本輪決定優先於舊 plan 的版本用字。以下原文與題庫相同。文件的刪節標記為〔略〕，正文與遊戲則只顯示「……」。

## 第一幕：迷山：糧盡的困境

- 段落：P01；卷軸 id=0，act=1。
- 出現位置：森林小徑；入山取皮、迷路與缺糧後解鎖。

> 漢明帝永平五年，剡縣劉晨、阮肇共入天台取穀皮，迷不得返，經十餘日，糧食乏盡，饑餒殆死。

白話：漢明帝永平五年，剡縣的劉晨與阮肇進天台山取穀樹皮，迷路無法返回。十多天後，糧食吃完，幾乎餓死。

考點：「迷不得返」與「糧食乏盡」合起來，說明兩人面臨什麼處境？

答案：無法找到歸路，又缺少維生食物

說明：兩人既迷路又缺糧，生存受到威脅；後來吃桃子才出現轉機。

## 第二幕：攀桃：困境的轉機

- 段落：P02；卷軸 id=1，act=2。
- 出現位置：山壁與桃樹旁；攀葛吃桃後解鎖。

> 遙望山上有一桃樹，大有子實，而絕岩邃澗，了無登路。攀葛乃得至，啖數枚，而饑止體充。

白話：遠遠看見山上有棵桃樹，結了很多果實；岩壁陡峭、山澗幽深，沒有登上的路。他們攀著葛藤才到達，吃了幾顆桃子後，止住飢餓，恢復體力。

考點：「而饑止體充」在故事發展上，主要有什麼作用？

答案：呈現體力恢復，使探路得以繼續

說明：「饑止體充」寫飢餓消除、體力恢復，讓原本幾乎餓死的兩人能繼續行動。

## 第三幕：流杯：沿水發現線索

- 段落：P03；卷軸 id=2，act=3。
- 出現位置：溪邊取水處；觀察菜葉、杯子與杯中飯粒後解鎖。

> 復下山持杯取水，欲盥漱，見蕪菁葉從山腹流出，甚鮮新。復一杯流出，有胡麻糝。相謂曰：「此處去人徑不遠。」度山出一大溪。

白話：兩人下山拿杯子取水，想洗手漱口，看見新鮮的蕪菁葉從山腹漂出；又漂出一只杯子，裡面有芝麻飯粒。他們認為附近有人行的路，越過山後到了一條大溪。

考點：這段文字呈現的事情，先後順序是哪一項？

答案：取水見漂流物，再推知人徑不遠

說明：先有取水時的觀察，再有「去人徑不遠」的判斷，最後才寫到大溪；兩人此時尚未見到女子。

## 第四幕：仙村：美景中的思歸

- 段落：P04–P06；卷軸 id=4，act=4。
- 出現位置：女子住處；迎接、款待、半年轉場與求歸送行後解鎖。

> 溪邊有二女子，姿質妙絕，見二人持杯出，便笑曰：「劉、阮二郎捉向所失流杯來。」晨、肇既不識之，二女便呼其姓，如似有舊，相見忻喜，問：「來何晚耶？」因要還家。
> 家筒瓦屋，南壁及東壁下各有一大床，皆施絳羅帳，角懸鈴，上金銀交錯，床頭各十侍婢。便敕云：「劉、阮二郎，經涉山阻，向雖得瓊實，猶尚虛弊，可速作食。」有胡麻飯、山羊脯，甚美。食畢行酒，有群女來，各持三五桃子，笑而言：「賀汝婿來。」酒酣作樂，劉、阮忻怖交並。
> ……遂停半年。氣候草木是春時，百鳥鳴呼，更懷土，求歸甚苦。女曰：「當如何？」遂呼前來女子有三四十人集會奏樂，共送劉、阮，指示還路。

白話：溪邊的兩名女子叫出劉、阮的姓，邀他們回家。屋頂覆筒瓦，屋內有紅色羅帳與鈴飾，並以食物款待。……兩人停留半年，氣候草木像春天，鳥聲使他們更思念家鄉，苦求返家。女子們奏樂送行，指出歸路。

考點：仙村有美食與春景，兩人為何仍然「求歸甚苦」？

答案：聽見百鳥鳴叫，因此更深思念故鄉

說明：「百鳥鳴呼，更懷土」直接連結鳥聲與思鄉。生活舒適，仍不能消除兩人對故鄉的牽掛。

## 第五幕：歸鄉：陌生的故鄉

- 段落：P07；卷軸 id=5，act=5。
- 出現位置：返鄉村落；發現人事全非、問到七世孫後解鎖。

> 既出，親舊零落，邑屋全異，無復相識。問得七世孫，傳聞上世入山，迷不得歸。

白話：出山後，親友已凋零，村落房屋全變了，也沒有認識的人。問到自己的七世孫，才知道後人傳說祖先入山迷路，未能返回。

考點：哪些訊息最能互相印證，說明故鄉已經過漫長歲月？

答案：屋舍改變且遇見七世孫，親友也已凋零

說明：故鄉屋舍與人事的改變，再加上七世孫的出現，共同顯示人間已過多代；不能只憑屋舍改變判定代數。

## 版本與互動界線

- 第一幕 Y 是「取穀皮」「經十餘日」；五棵樹、五格飢餓值是遊戲規則，不是原文數字，旁白不冒稱原文寫五棵。
- 第二幕用「啖數枚」「攀葛乃得至」，不沿用舊 plan 的「各噉數枚」。
- 第三幕三種線索是蕪菁葉、杯、胡麻飯粒；Y 逐字作「胡麻糝」「此處去人徑不遠」。W 長本作「胡麻飯糝」「此知去人徑不遠」，僅在異文表對照。Y 無「逆流二三里」，不加入旁白或引文。
- 第三幕加題 id=3、act=3，requires=[2]；應在第三幕觀察線索後觸發，與第三幕卷軸是兩筆可計分題。
- 第四幕為「筒瓦屋」，瓦的形狀不代表銅材質。留宿段整段〔略〕，只用「遂停半年」轉場；正文以「……」標省略，省去文字不翻譯、不出題。Y「百鳥鳴呼」保留，不改成舊 plan 的「百鳥啼鳴」。
- 第五幕用「邑屋全異」「問得七世孫」，不換成他本「邑屋改異」「問訊得七世孫」。七世不可換算成固定七百年。

## 結局與資料介接

結局 id=6、act=5，唯一 isEnding=true。original 是七段刪節整理本全文，含段落換行，沒有另加題名；白話也只摘要保留情節。題目「為什麼回家已是七世？」以異境與人間時間落差為合理推論，不假稱原文明說固定換算率。feedback 不提省略內容。

`clues.json` 共7筆，answer 為0起算，wrongHints 每題2條，options 每題4項。六筆非結局中，第3幕有兩筆，其餘每幕一筆。頂層不另放 infer，避免同題重複。endingText 明填本篇來源，避免落入舊專案的預設揭曉文。

`compare.json` 是 rows: [{aspect, liuruan, taohua}]；`narration.json` 是 acts: [{act, sentences}]。每個句子為一個陣列元素，無人物新台詞。旁白與比較表仍須 S／U 線串接；既有 ClueData 沒有 act，須由該線處理。本輪不改 C#、場景或 Prefab，也不操作 Unity。
